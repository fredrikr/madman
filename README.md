# Madman
A text adventure in Inform 6 + NAIL

This is a small text adventure, which was originally written by Ove Friman, in the Basic programming language, for the Commodore VIC-20 home computer.

This port uses the [NAIL framework](https://github.com/fredrikr/nail).

## Credits

This game was written by Ove Friman, some time in the 80s.

I, Fredrik Ramsberg, ported it to Inform 6 + NAIL, in 2026.
